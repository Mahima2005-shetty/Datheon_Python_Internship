
# Hangman Word Guessing Game

A console-based Hangman game developed using Python 3
for Task 1 of the Datheon Python Programming Internship.

## Features
- Random English word selection
- Six incorrect guesses allowed
- ASCII gallows display
- Hidden word with revealed letters
- Guessed-letter tracking
- Duplicate guess prevention
- Input validation
- Win and lose messages

## Requirements
- Python 3.8 or later

No external libraries are required.

## How to Run
1. Install Python 3.
2. Open the project folder in PowerShell.
3. Run:

   python hangman.py

4. Enter one English letter at a time to guess the word.

## Project Files
- hangman.py: Main game code
- README.md: Project documentation

Python functions, loops, conditionals, lists, sets,
strings, random selection, and input validation.
