
# Hangman Word Guessing Game

A Python console game developed for Task 1 of the
Datheon Python Programming Internship.

## Features
- Random English word selection
- Six incorrect guesses allowed
- ASCII gallows display
- Masked word display
- Guessed-letter tracking
- Duplicate guess prevention
- Input validation
- Win and lose messages

## Requirements
- Python 3.8 or later

No external libraries are required.

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:

   python hangman.py

4. Guess the hidden word by entering one English letter at a time.
